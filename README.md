```markdown
# fs-gateway-audit
> 分布式存储文件网关 NFS 基线审计脚本 V1.0（极简版）

## 简介
我是分布式存储运维工程师，日常做等保巡检、存储网关季度自查时，经常需要核查NFS导出配置。
通用扫描工具并发高，不敢直接在生产存储上跑；手动执行`showmount`效率低，缺少标准化风险定级与整改建议。

本脚本为**极简单文件Python工具**，调用系统原生`showmount -e`命令，**纯只读审计**，不会挂载、修改任何业务数据，低风险适配生产存储网关巡检场景。

> 当前版本：仅支持NFS审计，检测2项高危配置
> 1. NFS导出权限为 `*`（允许任意主机挂载）
> 2. 导出目录开启 `no_root_squash`

## ✨ 特性
- 单文件脚本，仅依赖系统命令，使用Python标准库，无需额外安装Python第三方包
- 支持指定单个IP扫描，也支持批量读取IP清单文件扫描
- 输出Markdown表格报告，包含：检查项、当前配置、风险等级、修复建议，可直接粘贴到工单、等保文档
- 完善异常捕获：处理目标不可达、nfs-utils未安装、命令超时等场景，中文友好提示
- 串行顺序扫描，无并发，最大程度避免对存储网关造成业务压力

## ⚠️ 免责声明（必看）
1. 本工具**仅允许在拥有授权的资产上进行安全审计**，禁止对未授权的服务器、存储设备扫描探测。
2. 脚本仅调用`showmount`读取NFS导出配置，无任何写入、渗透、爆破功能。
3. 使用本工具产生的一切后果，由使用者自行承担。

## 📦 环境准备
推荐 Ubuntu / WSL2 Ubuntu
```bash
sudo apt update
sudo apt install -y nfs-common python3
```

## 🚀 使用方法
### 查看帮助信息
```bash
python3 fs_audit.py --help
```

### 扫描单个存储网关IP
```bash
python3 fs_audit.py --target 192.168.1.100
```

### 批量扫描，从文本加载IP列表
新建`ips.txt`，一行填写一个IP：
```
192.168.1.100
192.168.1.101
```
执行批量扫描命令：
```bash
python3 fs_audit.py --target-file ips.txt
```

### 将扫描结果保存为Markdown报告文件
```bash
python3 fs_audit.py --target 192.168.1.100 --output report.md
```

## 📋 输出示例
| 检查项 | 当前配置 | 风险等级 | 修复建议 |
|--------|----------|----------|----------|
| NFS导出允许所有主机访问 | /data *(rw,no_root_squash) | 高危 | 限制访问客户端网段，移除`*`，仅添加可信业务主机 |
| NFS开启no_root_squash | /data *(rw,no_root_squash) | 高危 | 关闭no_root_squash，启用root_squash，防止客户端root篡改服务端文件 |
